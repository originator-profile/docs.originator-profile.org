# Content Attestation Error Reference

This page provides a reference for error codes related to [Content Attestation](../../opb/ca.md).

These errors may occur during the Content Attestation verification process.

For each error code, you can review its cause, example scenarios in which it may occur, and the recommended resolution.
Refer to this section when error codes such as `ERR_CONTENT_ATTESTATION_INVALID` or `ERR_CONTENT_ATTESTATION_VERIFY_FAILED` appear in the details view.
