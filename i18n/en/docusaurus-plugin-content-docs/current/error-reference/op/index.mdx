# Originator Profile Error Reference

This page provides a reference for error codes related to Originator Profile.

These errors may occur during the Originator Profile verification process.

For each error code, you can review its cause, example scenarios in which it may occur, and the recommended resolution.
Refer to this section when error codes such as `ERR_CERTIFICATE_EXPIRED`, `ERR_CORE_PROFILE_NOT_FOUND`, `ERR_ORIGINATOR_PROFILE_INVALID`, or `ERR_ORIGINATOR_PROFILE_VERIFY_FAILED` appear in the details view.
