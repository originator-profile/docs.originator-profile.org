# VC Error Reference

This page provides a reference for error codes related to [VC](../../opb/op-vc-data-model.md).

These errors may occur during the VC verification process.

For each error code, you can review its cause, example scenarios in which it may occur, and the recommended resolution.
Refer to this section when error codes such as `ERR_VC_DECODE_FAILED` or `ERR_VC_VERIFY_FAILED` appear in the details view.
