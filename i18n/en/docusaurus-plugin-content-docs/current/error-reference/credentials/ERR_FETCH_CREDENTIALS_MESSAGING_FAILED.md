# ERR_FETCH_CREDENTIALS_MESSAGING_FAILED

## Error Code: ERR_FETCH_CREDENTIALS_MESSAGING_FAILED

This error occurs when the message exchange for retrieving the credential fails.

## Error Message

- "Fetch frame credentials error occurred"

## Causes

- Communication with one or more frames within the tab may have failed.

## Resolution

- Check your network communication environment and try using the extension again.
