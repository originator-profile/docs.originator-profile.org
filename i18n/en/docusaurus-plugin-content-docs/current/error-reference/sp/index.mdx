# Site Profile Error Reference

This page provides a reference for error codes related to [Site Profile](../../opb/site-profile.md).

These errors may occur during the Site Profile verification process.

For each error code, you can review its cause, example scenarios in which it may occur, and the recommended resolution.
Refer to this section when error codes such as `ERR_SITE_PROFILE_FETCH_FAILED`, `ERR_SITE_PROFILE_FETCH_INVALID`, `ERR_SITE_PROFILE_INVALID`, or `ERR_SITE_PROFILE_VERIFY_FAILED` appear in the details view.
