# Error Code List

This is documentation for error codes, such as verification failures, that may appear when using the [Extensions](/web-ext) or [Debugging Tool](/debugger) to verify a Site Profile, Originator Profile Set, or Content Attestation Set.

The error code page for each code explains the cause and solution.
