# Content Attestation Set Error Reference

This page provides a reference for error codes related to [Content Attestation Set](../../opb/content-attestation-set.md).

These errors may occur during the Content Attestation Set verification process.

For each error code, you can review its cause, example scenarios in which it may occur, and the recommended resolution.
Refer to this section when error codes such as `ERR_CONTENT_ATTESTATION_SET_VERIFY_FAILED` appear in the details view.
