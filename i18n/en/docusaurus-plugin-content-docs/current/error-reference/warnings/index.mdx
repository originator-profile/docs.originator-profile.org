# Warning and Information Reference

This is a reference for warnings (`WARN_*`) and information (`INFO_*`) that are reported during verification but are not treated as verification failures.

For each notification, you can review the conditions under which it occurs, its message, and the recommended resolution.
Refer to this section when the verification result includes codes such as `WARN_CERTIFICATE_DEPRECATED`, `WARN_VISIBLE_TEXT_TARGET_INTEGRITY_DEPRECATED`, `WARN_DIGEST_SRI_MISSING`, `WARN_DIGEST_SRI_INVALID`, `INFO_PA_ISSUER_NOT_REGISTERED`, or `UNSPECIFIED`.
