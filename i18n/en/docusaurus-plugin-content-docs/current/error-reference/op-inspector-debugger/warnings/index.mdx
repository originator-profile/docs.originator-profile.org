# 警告・情報に関するエラーリファレンス

検証の失敗とは扱われないものの、検証中に通知される警告 (`WARN_*`) と情報 (`INFO_*`) に関するリファレンスです。

各通知について、発生する条件、通知のメッセージ、推奨される対処方法などを確認できます。
詳細情報画面に `WARN_CERTIFICATE_DEPRECATED`、`WARN_VISIBLE_TEXT_TARGET_INTEGRITY_DEPRECATED`、`WARN_DIGEST_SRI_MISSING`、`WARN_DIGEST_SRI_INVALID`、`INFO_PA_ISSUER_NOT_REGISTERED`、`UNSPECIFIED` のコードが表示された場合などに参照してください。
