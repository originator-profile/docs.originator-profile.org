# credentials Error Reference

This page provides a reference list for error codes related to credentials.

These errors may occur during the credentials fetch process.

For each error code, you can review its cause, example scenarios in which it may occur, and the recommended resolution.
Refer to this section when error codes such as `ERR_FETCH_CREDENTIALS_MESSAGING_FAILED` appear in the details view.
