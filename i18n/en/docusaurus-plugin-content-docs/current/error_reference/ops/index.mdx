# Originator Profile Set Error Reference

This page provides a reference for error codes related to [Originator Profile Set](../../opb/originator-profile-set.md).

These errors may occur during the Originator Profile Set verification process.

For each error code, you can review its cause, example scenarios in which it may occur, and the recommended resolution.
Refer to this section when error codes such as `ERR_ORIGINATOR_PROFILE_SET_INVALID` or `ERR_ORIGINATOR_PROFILE_SET_VERIFY_FAILED` appear in the details view.
