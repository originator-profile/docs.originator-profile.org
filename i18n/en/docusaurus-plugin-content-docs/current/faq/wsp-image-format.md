# Site Image Format

The site image you submit upon OP registration should meet the following requirements.

## Requirements for the Production OP Registration Site

- Dimensions: 512px by 512px or larger
- Image Format: One of the following:
  - PNG
  - JPEG
  - WebP

## Requirements for the OP Extension

- Ensure appropriate padding (to meet the isolation guidelines of each corporation/organization).
- A visual that holds up when scaled down while maintaining its aspect ratio (to 240px×44px).

Please check the [Display area of images in Website Profile](https://docs.originator-profile.org/en/inspector/#website-profile-image) to see how the image will be displayed in the OP extension.
