# Logo Image Format

The logo image you submit upon OP registration should meet the following requirements.

## Requirements for the Production OP Registration Site

- Dimensions: 396px by 396px or larger
- Image Format: One of the following:
  - PNG
  - JPEG
  - WebP

## Requirements for the OP Extension

- The image must look natural when displayed as an icon in a square area.
- Ensure appropriate padding (to meet the isolation guidelines of each corporation/organization).
- A visual that holds up when scaled down while maintaining its aspect ratio (to 44px×44px).

Please check the [Display Area for the OP Extension](https://docs.originator-profile.org/en/inspector/#displaying-images) to see how the image will be displayed in the OP extension.
