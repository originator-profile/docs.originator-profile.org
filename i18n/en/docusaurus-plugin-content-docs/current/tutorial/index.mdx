# Originator Profile (OP) Implementation Guide

This section summarizes the information common to implementing OP support.

## Overall Workflow

1. [OP Registration](#1-op-registration)  
   Enter and submit your organization's details on the OP registration site to receive an OPS.
2. [Setting up the Site Profile](/tutorial/sp-setup-guide/)  
   Create and deploy the Site Profile (`.well-known/sp.json`).
3. [Setting up Content Attestation](/tutorial/cas-setup-guide/)  
   Create and deploy Content Attestation for each piece of content.
   - Determine the content to be verified
     - Refer to "About Content and HTML Elements Subject to Verification" (This document is currently under preparation.)
   - Implementation based on Site Type
     - [Implementation for WordPress sites](/site-cases/wordpress/): You can utilize "CA Manager," an automated CA issuance tool.
4. [Verifying Operation with OP Inspector](#4-verifying-operation-with-op-inspector)

For details, please check the following documents: "Originator Profile Implementation Guide" and "How Originator Profile Works."

### 1. OP Registration

OP registration involves registering your organization's information as a content publisher.
To register for OP, you must enter and submit your organization's details on the OP registration site.
Once the submitted information is verified, you will receive an OPS.

#### If You Cannot Register for OP

Even if you cannot register for OP, you can use the following tools to issue test Site Profiles and Content Attestations to verify the OP implementation workflow.
Please refer to the respective guides for detailed usage instructions.

- [Content Attestation Server Playground](/playground/)
  Allows for the issuance of Site Profiles and Content Attestations.
- [OPVC CLI](/opvc-cli/)
  Enables the issuance of Core Profiles, Profile Annotations, Web Media Profiles, and Website Profiles, as well as Content Attestations.

### 2. Setting Up a Site Profile

To make a site OP-compliant, you must create and set up a Site Profile.

- Site Profile Overview → [Site Profile Documentation](/opb/site-profile/)
- Steps for Creating and Setting Up a Site Profile → [Site Profile Setup Guide](/tutorial/sp-setup-guide/)

### 3. Setting Up Content Attestation

To make content OP-compliant, you must create and set up a Content Attestation.

- Content Attestation Overview → [Content Attestation Documentation](/opb/ca/)
- Steps for Creating and Setting Up Content Attestation → [Content Attestation Setup Guide](/tutorial/cas-setup-guide/)

#### Support by Site Type

We provide tools to facilitate OP compliance for the following types of sites:

- WordPress: [WordPress Plugin (CA Manager)](/site-cases/wordpress/) for automatic CA issuance

### 4. Verifying Operation with OP Inspector

OP Inspector is a browser extension that allows you to view and verify Originator Profiles and Content Attestations directly in your web browser.
For details, please refer to the [OP Inspector Documentation](/inspector/).

:::note

OP Inspector is available in both standard and test build versions.

- For verification in a production environment → Standard build version
- When using the Content Attestation Server Playground → Test build version

For more information, please refer to the [Verification Method section of the Content Attestation Server Playground](/playground/#verification-method).

:::
