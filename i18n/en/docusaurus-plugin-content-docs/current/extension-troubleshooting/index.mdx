# 拡張機能のトラブルシューティング

このページでは、Originator Profile 拡張機能を使用する際に発生する可能性のある問題とその解決方法について説明します。

## サイトプロファイルのオーバーレイでロゴ画像が表示されない

画像ファイルが取得できないか、CORS ポリシーによりブロックされている可能性があります。

以下を確認してください。

1. 指定した URL のファイルが存在するか（404 エラーになっていないか）
2. ブラウザの開発者ツールのコンソールで CORS エラーが発生していないか
3. 画像を配信しているサーバーが CORS を許可しているか
