# WordPress plugin v0.4.1

## Release Information

- **Version**: 0.4.1
- **Release Date**: Dec 22, 2025
- **GitHub**: https://github.com/originator-profile/originator-profile/releases/tag/v0.4.1

---

:::note
This release only fixes bugs in the WordPress plugin; there are no changes to the extensions.
:::

:::warning
Version 0.4 introduces breaking changes to CA image elements; therefore, if you are updating the WordPress plugin from version 0.3, you must reissue any CAs containing images that were generated prior to the update.
:::

## What's Changed

- fix(wordpress): Fixed 'headline' and 'description' to required fields by @kou029w in https://github.com/originator-profile/profile-share/pull/266

**Full Changelog**: https://github.com/originator-profile/originator-profile/compare/v0.4.0...v0.4.1
