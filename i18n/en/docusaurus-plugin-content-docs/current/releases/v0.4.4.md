# Browser extension v0.4.4

## Release Information

- **Version**: 0.4.4
- **Release Date**: Jan 19, 2026
- **GitHub**: https://github.com/originator-profile/originator-profile/releases/tag/v0.4.4

---

:::note
This release only fixes bugs in the browser extension. There are no changes to the WordPress plugin.
:::

## Changes

- Corrected CA display problem in subframes - Fixed an issue where even if CA was installed in a subframe such as an iframe, it would not be displayed if there was no CA in the top level frame. This will ensure that CAs are collected and displayed correctly from all frames within the page. (#282)

**Full Changelog**: [v0.4.3...v0.4.4](https://github.com/originator-profile/originator-profile/compare/v0.4.3...v0.4.4)
