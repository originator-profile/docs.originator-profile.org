# v0.2.0-beta.2

## Release Information

- **Version**: 0.2.0-beta.2
- **Release Date**: Jun 27, 2025
- **GitHub**: https://github.com/originator-profile/originator-profile/releases/tag/v0.2.0-beta.2

---

:::warning
This release is a **beta version** intended for functional testing and compatibility verification.

Please note that the following features are scheduled to be added by the official release but are not included at this time.

- 🧩 Extension support for the new OP Registry (Note: OP verification currently fails)

:::

### ✅ New features added

- WordPress plugin support for the new CA server
- OPS verification: Interim support for multiple CP Issuers
- Enhanced development support: Implementation of OPS/CAS verification and debugging functions
- UI/UX improvements: Custom modal dialog implementation, support for displaying error messages as a list, and improved messages for Target Integrity verification failures
- Model expansion: Addition of OnlineAd and Profile Annotation models
- Development support: Integration of CAS Generator into the profile repository, support for issuing specific CASs individually, and internationalization

### 🛠️ Fixes

- CA Server: Fixed issues with malformed HTML requests and HTTP 500 errors
- Fixed issue where PEM keys failed to load

### 🔥 Removal & Deprecation

- Legacy data model support: Removed legacy OP/DP and legacy models
- Category-related: Removed `Category` and updated related references

### 🧪 Testing & Quality

- Refactored tests to use fixtures
- Removed the `Role` type and streamlined build dependencies for registry-ui
- Added support for automatic ESLint fixing in GitHub Actions

### 📄 Documentation

- Organizing API endpoints, improving CA documentation, preparing external-facing documentation, and adding review guidelines

### 📦 Build, CI/CD, and Dependency Management

- Version updates and security patches for tools such as Vite and Fastify
- Improvements to release workflows
- Migration to Tailwind CSS v4
- Enhancement of Turborepo caching
