## 主な変更点

### 掲載先URL制限プロパティの一貫性向上 https://github.com/originator-profile/profile-share/issues/70

- CAの掲載先の制限を`allowedUrl` URL Pattern に統一
- 当初`allowedOrigin`と`allowedUrl`の2つのプロパティを用意していたが`allowedUrl`の型をURL Pattern仕様に対応したことでOriginの場合に別のプロパティで指定する必要はなくなったため

### Website Profile の `url` プロパティの変更

- WSP の credentialSubject `url` を `allowedOrigin` に変更
  - 同一の「サイト」を(http,httpsの違いなど)複数Originでデプロイされることもあるため`allowedOrigin`は複数配列で指定可能
  - 開発環境で検証系やブランチデプロイでも有効とする場合にも利用可

### Web Media Profile descriptionプロパティの構造の変更 https://github.com/originator-profile/profile-share/issues/83

- { type, data } プロパティを持つオブジェクトと文字列 (string) で混在していた description プロパティの構造を string 型で統一

### 用語変更 (Target Integrity ⇒ **Content Integrity Descriptor)**

- 旧 Target Integrity 仕様の名前変更 (ドキュメントのみ)

## ✅ 新機能追加

- **fetcher関数の依存性注入対応** - `sign`および`verify`機能でfetcher関数を注入可能に修正
- **デモページの拡充** - OPSとCASのデモページにアクセスして検証できる機能を配置
- **WebMediaProfile型改善** - `description`プロパティの型を`string`に変更
- **WebsiteProfile API変更** - `url`プロパティを`allowedOrigin`に置換（BREAKING CHANGE）
- **WordPress プラグイン機能拡張** - 保持したCASをリンク形式で埋め込む機能を追加

## 🛠️ 修正

- **WordPress Plugin CA Manager脆弱性修正** - セキュリティ脆弱性を修正
- **ビルド設定修正** - publish用package.jsonの調整でビルドが可能に修正
- **web-ext e2eテスト修正** - e2eテストが通るように修正
- **依存関係更新** - 全依存関係を最新版に更新

## 🔥 削除・廃止
