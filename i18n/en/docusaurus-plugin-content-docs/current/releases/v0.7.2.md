# v0.7.2

## Release Information

- **Version**: 0.7.2
- **Release Date**: TBD
- **GitHub**: https://github.com/originator-profile/originator-profile/releases/tag/v0.7.2

---

Profile Annotation Issuer Registration PA has been renamed to "Profile Annotation Issuer Accreditation PA", and `IssuerAccreditation` has been added to `credentialSubject.type`. → [Documentation](https://docs.originator-profile.org/opb/pa-model/issuer-accreditation/)
PA using the previous type, `ProfileAnnotationIssuerRegistration`, can still be used for verification and for confirming the authorization of the PA issuer, just as before.

v0.7.1:

```json
{
  "credentialSubject": {
    "type": "ProfileAnnotationIssuerRegistration"
  }
}
```

v0.7.2:

```json
{
  "credentialSubject": {
    "type": "IssuerAccreditation"
  }
}
```

## OP Inspector

### Changed

- The PA issuer authorization check now recognizes both the new and legacy PA types as Profile Annotation Issuer Accreditation PA.
- We have also ensured that the new type of Accreditation PA is not displayed, just like the previous type.

### Fixed

- Fixed an issue where the verification of a PA issuer's authorization would fail with an exception (`annotationScheme is not iterable`) when a credential PA lacked a `credentialSubject.annotationScheme` property.
  Such Accreditation PAs are now skipped.

## npm package

### Added

- `@originator-profile/model`: Added the `IssuerAccreditation` schema and type for the accreditation PA.
- `@originator-profile/verify`: Added `isIssuerAccreditation` (to determine whether a given PA is an accreditation PA) and `verifyAnnotationIssuerAccreditation` (to verify the authorization of a PA issuer based on an accreditation PA).
  Both functions treat both the old and new types as Accreditation PA.

### Changed

- **Breaking Change** `@originator-profile/verify`: The `type` of the `info` notification issued when the authorization of a PA issuer cannot be verified has been changed from `INFO_PA_ISSUER_NOT_REGISTERED` to `INFO_PA_ISSUER_NOT_ACCREDITED`. → [Error Reference](https://docs.originator-profile.org/error-reference/INFO_PA_ISSUER_NOT_ACCREDITED/)
  Added `ProblemType.PaIssuerNotAccredited`.
  Since `ProblemType.PaIssuerNotRegistered` also refers to the same value, code that performs comparisons using constants will continue to work without needing any changes.
  Code that compares the `type` URL as a string needs to be rewritten.
- `@originator-profile/verify`: Updated the informational notification text to use "accredited" instead of "registered".

v0.7.1:

```text
https://docs.originator-profile.org/error-reference/INFO_PA_ISSUER_NOT_REGISTERED/
Profile Annotation Issuer is not registered for this annotation scheme
```

v0.7.2:

```text
https://docs.originator-profile.org/error-reference/INFO_PA_ISSUER_NOT_ACCREDITED/
Profile Annotation Issuer is not accredited for this annotation scheme
```

### Deprecated

- `@originator-profile/model`: `ProfileAnnotationIssuerRegistration` has been deprecated.
  Please migrate to `IssuerAccreditation`.
- `@originator-profile/verify`: `isProfileAnnotationIssuerRegistration` has been deprecated.
  This function checks only the legacy type.
  Please migrate to `isIssuerAccreditation`.
- `@originator-profile/verify`: `verifyAnnotationIssuerRegistration` has been deprecated.
  It remains available as an alias for `verifyAnnotationIssuerAccreditation`.
- `@originator-profile/verify`: `ProblemType.PaIssuerNotRegistered` has been deprecated.
  Please migrate to `ProblemType.PaIssuerNotAccredited`.

### Fixed

- `@originator-profile/verify`: `verifyAnnotationIssuerAccreditation` has been updated to skip accreditation PA that lack a `credentialSubject.annotationScheme`.
  Previously, this would have resulted in an exception and failure.
