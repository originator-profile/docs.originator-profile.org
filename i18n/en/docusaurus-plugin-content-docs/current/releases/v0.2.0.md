# v0.2.0

## Release Information

- **Version**: 0.2.0
- **Release Date**: Jul 7, 2025
- **GitHub**: https://github.com/originator-profile/originator-profile/releases/tag/v0.2.0

---

### ✅ New Features Added

- WordPress plugin support for the new CA server
- OPS verification: Interim support for multiple CP Issuers
- Enhanced development support: Implementation of OPS/CAS verification and debugging functions
- UI/UX improvements: Custom modal dialog implementation, support for displaying error messages as a list, and improved messages for Target Integrity verification failures
- Model expansion: Addition of OnlineAd and Profile Annotation models
- Development support: Integration of CAS Generator into the profile repository, support for issuing specific CASs individually, and internationalization

### 🛠️ Fixed

- Fixed an issue where loading PEM keys failed.

### 🔥 Deletion & Abolition

- Legacy data model support: Complete removal of legacy OP/DP and legacy models
- Category-related: Removal of `Category` and updates to associated references

### 🧪 Testing & Quality

- Refactor tests to use fixtures
- Add support for automatic ESLint fixing in GitHub Actions

### 📄 Documentation

- Preparation of external-facing documentation and addition of review guidelines.

### 📦 Build, CI/CD, and Dependency Management

- Version updates and security patches (e.g., Vite)
- Release workflow improvements
- Migration to Tailwind CSS v4
- Turborepo cache enhancements
