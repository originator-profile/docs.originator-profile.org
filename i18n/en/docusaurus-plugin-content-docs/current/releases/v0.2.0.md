# v0.2.0

:::note
このページは翻訳中です。
:::

## Release Information

- **Version**: 0.2.0
- **Release Date**: Jul 7, 2025
- **GitHub**: https://github.com/originator-profile/originator-profile/releases/tag/v0.2.0

---

### ✅ 新機能追加

- WordPress プラグインの新 CA サーバー 対応
- OPS 検証: 複数 CP Issuers への暫定対応
- 開発支援機能の強化: OPS / CAS の検証・デバッグ機能の実装
- UI/UX 改善: モーダルダイアログの独自実装、エラーメッセージのリスト表示対応、Target Integrity 検証失敗時のメッセージ改善
- モデル拡張: OnlineAd や Profile Annotation モデルを追加
- 開発支援: CAS Generator を profile リポジトリに統合、特定 CAS の個別発行対応、国際化

### 🛠️ 修正

- PEM 鍵の読み込み失敗問題の修正

### 🔥 削除・廃止

- 旧データモデル対応: 旧 OP/DP や旧モデルの全面削除
- カテゴリ関連: `Category` の削除と関連参照の修正

### 🧪 テスト・品質

- fixture ベースへのテスト再構成
- GitHub Actions での eslint 自動修正対応

### 📄 ドキュメント

- 外部向けドキュメント整備、レビューガイドライン追加

### 📦 ビルド・CI/CD・依存管理

- Vite などのバージョン更新やセキュリティ対応
- release ワークフロー改善
- Tailwind CSS v4 移行
- Turborepo キャッシュ強化
