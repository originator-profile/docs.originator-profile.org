# v0.7.3

## Release Information

- **Version**: 0.7.3
- **Release Date**: Nov 18, 2026
- **GitHub**: https://github.com/originator-profile/originator-profile/releases/tag/v0.7.3

---

Support has been added for the CA Set media type `application/ca-set+json` and the OP Set media type `application/op-set+json`, as defined in [Media Types](https://docs.originator-profile.org/opb/media-types/).
The legacy media types `application/cas+json` and `application/ops+json` are now deprecated.
While these can still be used for verification, they will no longer be supported on or after November 1, 2027 (2027-11-01). → [Deprecated Media Types](https://docs.originator-profile.org/opb/media-types/#deprecated)

v0.7.2:

```html
<script type="application/cas+json">
  ...
</script>
```

v0.7.3:

```html
<script type="application/ca-set+json">
  ...
</script>
```

## OP Inspector

### Fixed

- Fixed an issue where a CA Set provided via a `script` element with the `type` attribute set to `application/ca-set+json` could not be validated, resulting in no CAs being displayed.
  Also enabled validation for OP Sets provided via `application/op-set+json`.
  CA Sets and OP Sets using older media types can still be validated as before.

## WordPress Plugin

### Changed

- **Breaking Change:** The `type` attribute of the `script` element used to provide a CA Set has been changed from `application/cas+json` to `application/ca-set+json`.
  This change applies both when the CA Set is embedded directly and when it is referenced as an external file.
  Additionally, the `Content-Type` for REST API responses that return a CA Set has been updated to `application/ca-set+json`.

:::warning
OP Inspector versions v0.7.2 or earlier cannot validate CA Sets in `application/ca-set+json` format.
If you update the WordPress plugin to v0.7.3, the CA for an article will no longer be displayed when using OP Inspector v0.7.2 or earlier.
Please also update OP Inspector to v0.7.3.
:::

## npm package

### Added

- `@originator-profile/presentation`: Added the media type constants `OPS_MEDIA_TYPE` (`application/op-set+json`) and `CAS_MEDIA_TYPE` (`application/ca-set+json`).
- `@originator-profile/presentation`: Added the arrays `OPS_ACCEPTED_MEDIA_TYPES` and `CAS_ACCEPTED_MEDIA_TYPES`, which contain the media types accepted by a verifier.
  Each includes both the new and old media types.

### Changed

- `@originator-profile/presentation`: `fetchCredentials`, `fetchOriginatorProfileSet`, and `fetchContentAttestationSet` have been updated to retrieve the OP Set and CA Set from `script` elements, supporting both legacy and current media types.
- **Breaking Change** `@originator-profile/vite-plugin`: The `type` attribute for `script` elements containing signed CA Sets has been changed from `application/cas+json` to `application/ca-set+json`.
- `@originator-profile/vite-plugin`: The `type` attribute for `script` elements containing unsigned CAs has been changed to `application/prs.originator-profile.unsigned-ca-set+json`.

### Deprecated

- `@originator-profile/presentation`: Added constants `DEPRECATED_OPS_MEDIA_TYPE` (`application/ops+json`) and `DEPRECATED_CAS_MEDIA_TYPE` (`application/cas+json`) to represent legacy media types, and marked them as deprecated.
  Support will be discontinued on or after November 1, 2027.
  Please migrate to `OPS_MEDIA_TYPE` and `CAS_MEDIA_TYPE`.
- `@originator-profile/vite-plugin`: The `application/prs.originator-profile.unsigned-cas+json` value for the `type` attribute of `script` elements—used to specify unsigned CAs—has been deprecated.
  It will continue to be accepted until November 1, 2027.
  Please migrate to `application/prs.originator-profile.unsigned-ca-set+json`.
