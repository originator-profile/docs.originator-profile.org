# Browser extension v0.3.1

## Release Information

- **Version**: 0.3.1
- **Release Date**: Oct 17, 2025
- **GitHub**: https://github.com/originator-profile/originator-profile/releases/tag/v0.3.1

---

:::note
The changes consist solely of bug fixes for the extension; there are no changes to the WordPress plugin.
:::

## What's Changed

- fix(web-ext): Deduplicate JWKs in the `getRegistryKeys()` function by @kou029w in https://github.com/originator-profile/profile-share/pull/157

Modified the `getRegistryKeys()` function to deduplicate JWKs when duplicate CP JWKs are registered.
This change maintains compatibility with v0.1.6.

**Full Changelog**: [v0.3.0...v0.3.1](https://github.com/originator-profile/profile-share/compare/v0.3.0...v0.3.1)
