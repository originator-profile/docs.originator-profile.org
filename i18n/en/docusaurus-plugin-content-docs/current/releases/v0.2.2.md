# v0.2.2

## Release Information

- **Version**: 0.2.2
- **Release Date**: Oct 17, 2025
- **GitHub**: https://github.com/originator-profile/originator-profile/releases/tag/v0.2.2

:::note
The changes consist solely of bug fixes for the extension; there are no changes to the WordPress plugin.
:::

## What's Changed

- fix(web-ext): Eliminated JWK duplicates in the getRegistryKeys() function by @kou029w in ([#157](https://github.com/originator-profile/originator-profile/pull/157))

Modified the `getRegistryKeys()` function to eliminate duplicates when CP JWKs are registered redundantly.
This change maintains compatibility with v0.1.6.
