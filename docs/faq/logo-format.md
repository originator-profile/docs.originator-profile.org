# ロゴ画像の形式

OP 登録時にご提出いただくロゴ画像は、次の要件を満たすようにご用意ください。

## 本番運用系 OP 登録サイトの要件

- 寸法: 幅 180px × 高さ 120px またはそれ以上
- アスペクト比: 3:2
- 画像形式: 次のいずれか
  - PNG
  - JPEG
  - WebP
- 背景: 白（`#fff`）として扱います。
  透過背景の画像は、白と合成して表示されます。
- 余白: 各辺に、画像の高さの 10% 以上の余白を確保してください（180px × 120px の画像なら 12px 以上）。
- ロゴの大きさ: ロゴの高さを画像の高さの 78〜80% にするか、ロゴの幅を画像の高さの 128〜130% にしてください（180px × 120px の画像なら、高さ 94〜96px または幅 154〜156px）。
  ロゴは余白の内側に収め、縦と横のどちらかの辺を余白の内側の領域いっぱいまで広げます。

各法人・組織にアイソレーション規定（ロゴ周囲に確保する余白の規定）がある場合は、この要件と各社の規定を比べ、余白の大きいほうに合わせてください。

## OP 拡張機能の要件

- 正方形領域にアイコンとして表示して不自然とならない
- 余白が適切（各法人・組織のアイソレーション規定を満たす）
- アスペクト比を保持した縮小（幅 44px × 高さ 44px）での閲覧に耐えるビジュアル

どのように OP 拡張機能で表示されるかについては、[OP 拡張機能の表示領域](https://docs.originator-profile.org/ja/inspector/#画像の表示)をご確認ください。
