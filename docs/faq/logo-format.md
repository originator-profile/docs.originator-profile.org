# ロゴ画像の形式

OP 登録時にご提出いただくロゴ画像は、次の要件を満たすようにご用意ください。

## 本番運用系 OP 登録サイトの要件

- 寸法: 縦横396pxまたはそれ以上
- 画像形式: 次のいずれか
  - PNG
  - JPEG
  - WebP

## OP 拡張機能の要件

- 正方形領域にアイコンとして表示して不自然とならない
- 余白が適切（各法人・組織のアイソレーション規定を満たす）
- アスペクト比を保持した縮小（幅 44px × 高さ 44px）での閲覧に耐えるビジュアル

どのように OP 拡張機能で表示されるかについては、[OP 拡張機能の表示領域](https://docs.originator-profile.org/ja/inspector/#画像の表示)をご確認ください。
