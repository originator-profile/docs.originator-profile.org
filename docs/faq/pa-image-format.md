# PA 画像の形式

Profile Annotation (PA) の画像（`credentialSubject.image`）は、次の要件を満たすようにご用意ください。
この画像は、組織のロゴ画像（[ロゴ画像の形式](/faq/logo-format/)）とは別のものです。

## 提出する画像の要件

- アスペクト比: 3:2
- 寸法: 幅 180px × 高さ 120px またはそれ以上
  拡大するときも 3:2 の比率を保ってください（例: 幅 360px × 高さ 240px）。
- 画像形式: 次のいずれか
  - PNG
  - JPEG
  - WebP
- 背景: 白（`#fff`）として扱います。
  透過背景の画像は、白と合成して表示されます。
- 余白: 各辺に、画像の高さの 10% 以上の余白を確保してください（180px × 120px の画像なら 12px 以上）。
- ロゴの大きさ: ロゴの高さを画像の高さの 78〜80% にするか、ロゴの幅を画像の高さの 128〜130% にしてください（180px × 120px の画像なら、高さ 94〜96px または幅 154〜156px）。
  ロゴは余白の内側に収め、縦と横のどちらかの辺を余白の内側の領域いっぱいまで広げます。

各法人・組織にアイソレーション規定（ロゴ周囲に確保する余白の規定）がある場合は、この要件と各社の規定を比べ、余白の大きいほうに合わせてください。

## OP 拡張機能での表示

PA の画像は、OP 拡張機能では幅 60px × 高さ 40px の表示領域にアスペクト比を保持して表示されます。
提出する画像の最小寸法（幅 180px × 高さ 120px）は、この表示領域の 3 倍にあたります。

- 表示領域より小さい画像は、等倍で中央に配置されます。
- 表示領域より大きい画像は、アスペクト比を保持して縮小されます。
- 画像が指定されていない場合は、プレースホルダー画像が表示されます。

画像の検証方法については、[`image` データ型](/opb/context/#the-image-datatype) を参照してください。
