# サイト画像の形式

OP 登録時にご提出いただくサイト画像は、次の要件を満たすようにご用意ください。

## 本番運用系 OP 登録サイトの要件

- 寸法: 縦横512pxまたはそれ以上
- 画像形式: 次のいずれか
  - PNG
  - JPEG
  - WebP

## OP 拡張機能の要件

- 余白が適切（各法人・組織のアイソレーション規定を満たす）
- アスペクト比を保持した縮小（幅 240px × 高さ 44px）での閲覧に耐えるビジュアル

どのように OP 拡張機能で表示されるかについては、[Website Profile の画像の表示領域](https://docs.originator-profile.org/ja/inspector/#website-profile-の画像)をご確認ください。
