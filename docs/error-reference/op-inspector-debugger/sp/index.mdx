# Site Profile に関するエラーリファレンス

[Site Profile](../../../opb/site-profile.md) に関するエラーリファレンスです。

Site Profile の検証プロセスにおいて発生するエラーを対象としています。

各エラーについて、原因、発生する状況の例、推奨される対処方法などを確認できます。
詳細情報画面にて `ERR_SITE_PROFILE_FETCH_FAILED`、`ERR_SITE_PROFILE_FETCH_INVALID`、`ERR_SITE_PROFILE_INVALID`、`ERR_SITE_PROFILE_VERIFY_FAILED` のエラーコードが表示された場合などに参照してください。
