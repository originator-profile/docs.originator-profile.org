# Originator Profile Set に関するエラーリファレンス

[Originator Profile Set](../../../opb/originator-profile-set.md) に関するエラーリファレンスです。

Originator Profile Set の検証プロセスにおいて発生するエラーを対象としています。

各エラーについて、原因、発生する状況の例、推奨される対処方法などを確認できます。
詳細情報画面にて `ERR_ORIGINATOR_PROFILE_SET_INVALID`、`ERR_ORIGINATOR_PROFILE_SET_VERIFY_FAILED` のエラーコードが表示された場合などに参照してください。
