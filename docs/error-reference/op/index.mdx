# Originator Profile に関するエラーリファレンス

Originator Profile に関するエラーリファレンスです。

Originator Profile の検証プロセスにおいて発生するエラーを対象としています。

各エラーについて、原因、発生する状況の例、推奨される対処方法などを確認できます。
詳細情報画面にて `ERR_CERTIFICATE_EXPIRED`、`ERR_CORE_PROFILE_NOT_FOUND`、`ERR_ORIGINATOR_PROFILE_INVALID`、`ERR_ORIGINATOR_PROFILE_VERIFY_FAILED` のエラーコードが表示された場合などに参照してください。
