# v0.7.3

## Release Information

- **Version**: 0.7.3
- **Release Date**: Nov 18, 2026
- **GitHub**: https://github.com/originator-profile/originator-profile/releases/tag/v0.7.3

---

[Media Types](https://docs.originator-profile.org/opb/media-types/) で定める CA Set のメディアタイプ `application/ca-set+json` と OP Set のメディアタイプ `application/op-set+json` に対応しました。
旧メディアタイプの `application/cas+json` と `application/ops+json` は非推奨です。
これらも引き続き検証できますが、2027-11-01 以降はサポート外になります。→ [非推奨のメディアタイプ](https://docs.originator-profile.org/opb/media-types/#deprecated)

v0.7.2:

```html
<script type="application/cas+json">
  ...
</script>
```

v0.7.3:

```html
<script type="application/ca-set+json">
  ...
</script>
```

## OP Inspector

### Fixed

- `type` 属性が `application/ca-set+json` の `script` 要素で提示した CA Set を検証できず、CA が 1 件も表示されなかった不具合を修正しました。
  `application/op-set+json` の OP Set も同様に検証できるようにしました。
  旧メディアタイプの CA Set と OP Set も、これまでどおり検証できます。

## WordPress プラグイン

### Changed

- **破壊的変更** 記事に CA Set を提示する `script` 要素の `type` 属性を、`application/cas+json` から `application/ca-set+json` に変更しました。
  CA Set を埋め込む場合と外部ファイルとして参照する場合のどちらも変更の対象です。
  CA Set を返す REST API のレスポンスの `Content-Type` も `application/ca-set+json` に変更しました。

:::warning
v0.7.2 以前の OP Inspector は、`application/ca-set+json` の CA Set を検証できません。
WordPress プラグインを v0.7.3 に更新すると、v0.7.2 以前の OP Inspector では記事の CA が表示されなくなります。
OP Inspector も v0.7.3 に更新してください。
:::

## npm パッケージ

### Added

- `@originator-profile/presentation`：メディアタイプの定数 `OPS_MEDIA_TYPE` (`application/op-set+json`) と `CAS_MEDIA_TYPE` (`application/ca-set+json`) を追加しました。
- `@originator-profile/presentation`：検証者が受理するメディアタイプの配列 `OPS_ACCEPTED_MEDIA_TYPES` と `CAS_ACCEPTED_MEDIA_TYPES` を追加しました。
  それぞれ新旧両方のメディアタイプを含みます。

### Changed

- `@originator-profile/presentation`：`fetchCredentials`、`fetchOriginatorProfileSet`、`fetchContentAttestationSet` は、新旧どちらのメディアタイプの `script` 要素からも OP Set と CA Set を取得するようにしました。
- **破壊的変更** `@originator-profile/vite-plugin`：署名した CA Set を出力する `script` 要素の `type` 属性を、`application/cas+json` から `application/ca-set+json` に変更しました。
- `@originator-profile/vite-plugin`：未署名の CA を記述する `script` 要素の `type` 属性を、`application/prs.originator-profile.unsigned-ca-set+json` に変更しました。

### Deprecated

- `@originator-profile/presentation`：旧メディアタイプを表す定数 `DEPRECATED_OPS_MEDIA_TYPE` (`application/ops+json`) と `DEPRECATED_CAS_MEDIA_TYPE` (`application/cas+json`) を追加し、非推奨としました。
  2027-11-01 以降はサポート外になります。
  `OPS_MEDIA_TYPE` と `CAS_MEDIA_TYPE` に移行してください。
- `@originator-profile/vite-plugin`：未署名の CA を記述する `script` 要素の `type` 属性 `application/prs.originator-profile.unsigned-cas+json` を非推奨としました。
  2027-11-01 までは引き続き受け付けます。
  `application/prs.originator-profile.unsigned-ca-set+json` に移行してください。
