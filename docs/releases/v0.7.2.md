# v0.7.2

## Release Information

- **Version**: 0.7.2
- **Release Date**: TBD
- **GitHub**: https://github.com/originator-profile/originator-profile/releases/tag/v0.7.2

---

Profile Annotation Issuer 登録証 PA を「Profile Annotation Issuer 認定証 PA」に改称し、`credentialSubject.type` に `IssuerAccreditation` を追加しました。→ [ドキュメント](https://docs.originator-profile.org/opb/pa-model/issuer-accreditation/)
旧 type `ProfileAnnotationIssuerRegistration` の PA も、これまでどおり検証と PA 発行者の認可の確認に使えます。

v0.7.1:

```json
{
  "credentialSubject": {
    "type": "ProfileAnnotationIssuerRegistration"
  }
}
```

v0.7.2:

```json
{
  "credentialSubject": {
    "type": "IssuerAccreditation"
  }
}
```

## OP Inspector

### Changed

- PA 発行者の認可の確認で、新旧どちらの type の PA も認定証 PA として扱うようにしました。
- 新しい type の認定証 PA も、旧 type と同じく表示しないようにしました。

### Fixed

- `credentialSubject.annotationScheme` を持たない認定証 PA があると、PA 発行者の認可の確認が例外 (`annotationScheme is not iterable`) で失敗していた不具合を修正しました。
  そのような認定証 PA は読み飛ばします。

## npm パッケージ

### Added

- `@originator-profile/model`：認定証 PA のスキーマと型 `IssuerAccreditation` を追加しました。
- `@originator-profile/verify`：認定証 PA かを判定する `isIssuerAccreditation` と、認定証 PA にもとづいて PA 発行者の認可を確認する `verifyAnnotationIssuerAccreditation` を追加しました。
  どちらも新旧両方の type を認定証 PA として扱います。

### Deprecated

- `@originator-profile/model`：`ProfileAnnotationIssuerRegistration` を非推奨としました。
  `IssuerAccreditation` に移行してください。
- `@originator-profile/verify`：`isProfileAnnotationIssuerRegistration` を非推奨としました。
  この関数は旧 type だけを判定します。
  `isIssuerAccreditation` に移行してください。
- `@originator-profile/verify`：`verifyAnnotationIssuerRegistration` を非推奨としました。
  `verifyAnnotationIssuerAccreditation` の別名として残しています。

エラーコード `INFO_PA_ISSUER_NOT_REGISTERED` とログメッセージは変更していません。

### Fixed

- `@originator-profile/verify`：`verifyAnnotationIssuerAccreditation` は、`credentialSubject.annotationScheme` を持たない認定証 PA を読み飛ばすようにしました。
  これまでは例外で失敗していました。
