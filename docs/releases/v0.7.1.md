## OP Inspector

### Fixed

- `credentialSubject.type` が `CertificateProperties` 以外の Profile Annotation (`Membership` や `NewsMediaRegistration` など) で、`image` プロパティの画像を表示せず、代わりのロゴを表示していた不具合を修正しました。
