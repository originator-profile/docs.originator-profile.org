# 拡張機能 v0.4.4

## Release Information

- **Version**: 0.4.4
- **GitHub**: https://github.com/originator-profile/originator-profile/releases/tag/v0.4.4

---

> [!NOTE]
> 本リリースは拡張機能の不具合修正のみです。WordPressプラグインは変更ありません。

> [!NOTE]
> This release only fixes bugs in extended functions. There are no changes to the WordPress plugin.

## 変更内容

- サブフレーム内のCA表示問題を修正 - iframe等のサブフレームにCAが設置されていても、トップレベルフレームにCAがない場合に表示されなかった問題を修正しました。これにより、ページ内の全フレームからCAが正しく収集・表示されるようになります。(#282)

**Full Changelog**: https://github.com/originator-profile/originator-profile/compare/v0.4.3...v0.4.4
