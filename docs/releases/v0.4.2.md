# WordPress プラグイン v0.4.2

## Release Information

- **Version**: 0.4.2
- **Release Date**: Dec 24, 2025
- **GitHub**: https://github.com/originator-profile/originator-profile/releases/tag/v0.4.2

---

:::note
本リリースはWordPressプラグインの不具合修正のみです。拡張機能は変更ありません。
:::

v0.4 では CA の画像要素への後方互換性のない変更が入っているため、もし v0.3 からお使いの WordPress プラグインをアップデートする場合、それ以前に発行した画像の含まれる CA を再発行する必要があります。
:::
