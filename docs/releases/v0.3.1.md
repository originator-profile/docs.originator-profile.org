## What's Changed

- fix(web-ext): getRegistryKeys()関数のJWK重複を排除 by @kou029w in https://github.com/originator-profile/profile-share/pull/157

CPのJWKが重複して登録されている場合にgetRegistryKeys()関数で重複を排除するように修正しました。
この変更によってv0.1.6との互換性が維持されます。

**Full Changelog**: [https://github.com/originator-profile/profile-share/compare/v0.3.0...v0.3.1](https://github.com/originator-profile/profile-share/compare/v0.3.0...v0.3.1)
